# Minkyo Kim — Portfolio Website

A single-page portfolio for college applications.

## Run locally

Open `index.html` in a browser, or use a local server:

```bash
cd /Users/kimminkyo/Desktop/Portfolio_cp
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## Customize

- Replace dashed **Image** placeholders with your photos in `index.html`.
- Swap the hero background by adding a background image to `.hero-bg-placeholder` in `styles.css`.
- Update `resume.pdf` with your full resume when ready.

## Colors & Typography

- Azure: `#0080FE`
- Off-white: `#FFFEFA`
- Font: Helvetica Neue
